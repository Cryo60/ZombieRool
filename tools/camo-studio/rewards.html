Récompenses du code

Coche autant de camos que tu veux. Les ZRF et l’XP s’ajoutent à la même récompense.

Camos aléatoires

Le tirage est fait à la génération, séparément pour chaque code, sans doublon dans un même code. Les exclusifs, prestiges et maîtrises nécessitent un choix explicite.

Destinataire et validité

Un UUID réserve le code à ce compte dans le client normal.

Chaque code contient toutes les récompenses choisies. Sans UUID, il est utilisable une fois par profil local ; ce nombre n’est pas une limite globale d’utilisations.
