# Organisateur d’inventaire ZombieRool

Ouvre `index.html` dans ton navigateur (double-clic). Le fichier fonctionne hors ligne et contient les icônes du mod.

- Crée tes catégories avec « Créer une catégorie ». Clique sur leur nom au centre pour les renommer, puis appuie sur Entrée.
- Glisse les objets dans une catégorie. Tu peux aussi en sélectionner plusieurs dans le catalogue à droite, choisir une destination et cliquer sur « Déplacer ».
- Glisse les catégories pour changer leur ordre. Glisse les objets au centre pour changer leur ordre dans la catégorie.
- « Armes (toutes) » représente toutes les armes : une seule vignette à placer, y compris pour TacZ.
- Les changements sont enregistrés automatiquement dans ce navigateur. « Annuler » permet de revenir en arrière.
- Quand tu as terminé, clique sur « Exporter le rangement » et transmets `ZombieRool-inventaire.json` dans le chat. Tu peux aussi réimporter ce fichier pour continuer ailleurs.

L’outil prépare le rangement ; il ne modifie pas directement le jeu.
