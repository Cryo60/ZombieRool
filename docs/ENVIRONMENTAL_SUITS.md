# Environmental equipment appearances

The Lunar Helmet has three cosmetic variants. Their oxygen protection, equip/remove animations,
sounds, equipment key, death/reset rules and shared secondary-equipment slot are identical.
Changing a variant does not change gravity or environment settings.

- `lunar`: Original Lunar helmet and visor, with an added white astronaut suit and life-support backpack.
- `diving`: Diving gear, dark wetsuit, face mask, regulator and twin tanks.
- `hazmat`: Hazmat suit, yellow coverall, filtered mask and breathing pack.

The creative inventory lists the three helmets in **Weapons** and the three matching stations in
**Machines**. The original `zombierool:lunar_helmet` and `zombierool:lunar_helmet_station` IDs remain
valid. Added IDs are `diving_helmet`, `diving_helmet_station`, `hazmat_helmet`,
`hazmat_helmet_station`, all in the `zombierool` namespace.

Place the desired two-block station and use the interaction key on either half. It grants the
matching equipment and starts the existing equip animation. A different variant replaces the
previous equipment; it does not consume or replace actual armor. Removing the equipment restores
the player's original skin. First-person arms use the same suit texture, including renderers that
query the player's skin, such as TacZ. The extra body geometry follows the final animated player
parts and uses ordinary entity rendering.

Map makers choose **Map Config → Player → Loadout → Suit equipped at match start**.
The list offers None (default), Astronaut, Diving and Hazmat. On match start the selected suit is
already equipped, without an animation or an unprotected delay. Ending the match removes it.
This setting is stored in `addonConfig["zombierool:lunar"].startingSuit` and is also editable via
the existing Lua map-config extension API. It does not continuously force a suit during gameplay.

Lua: `giveEnvironmentalSuit(uuid, "lunar" | "diving" | "hazmat")` grants the selected appearance.
As with `giveLunarHelmet`, call `setLunarHelmetEquipped(uuid, true)` to start equipping it.
`getLunarHelmetState(uuid).style` exposes the selected ID. Existing lunar API methods keep working.

Original assets are generated by `tools/prepare-environmental-suits.py`:

- `models/equipment/<style>.json`: helmet and body-mounted cuboids in player-part coordinates.
- `textures/entity/suits/<style>_suit.png`: standard 64×64 player UV texture.
- `textures/entity/suits/<material>.png`: small, shared original material textures.
- Matching item/block models and station blockstates.

The two added helmets and the three body outfits are original assets. The lunar helmet keeps its
existing mesh, materials, transparent visor and animation prop; the original player face remains
visible inside it. Resource packs can replace the textures
and block/item models. The equipment mesh JSON is loaded once per client session.
