# Configuration client ZombieRool

Depuis le menu principal : **MODS → ZombieRool → Config**. Le même écran est disponible dans les options Minecraft.

- **Apparence** : Halloween, modèles classiques, animation de l’arsenal et gore réduit.
- **HUD** : notifications XP et compteur d’ennemis restants.
- **En ligne** : requêtes réseau, présence Discord et identifiant d’application Discord.

**Enregistrer** applique les changements et les écrit dans `config/zombierool-client.toml`. **Annuler** ou Échap abandonne les changements. **Valeurs par défaut** réinitialise le brouillon ; il faut ensuite enregistrer pour appliquer les valeurs.

En partie, **Configuration de la map** ouvre les réglages du monde pour les opérateurs. Ces réglages restent propres au monde et sont vérifiés côté serveur.

La présence Discord se met à jour après l’enregistrement. Un identifiant vide la désactive.
