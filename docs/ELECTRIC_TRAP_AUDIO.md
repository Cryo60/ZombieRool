# Electric trap audio

`zombierool:electric_trap_loop` uses Electric Buzz by themightyglider, released under CC0:
https://opengameart.org/content/electric-buzz
Original source credited by the author: https://freesound.org/people/soundtracvkradio/sounds/394679/

Adaptation: mono, normalized peak, 80 ms tail/head crossfade for continuous looping. Playback is positional (24 blocks), one loop per active electric pad. It stops on deactivation, removal, chunk unload, disconnect and sound engine reload. The old beacon ambient is removed.
